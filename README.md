# Tessellae

*Like tessellae forming a mosaic, these projects connect the pieces.*

Open-source contributions by [Cyril Soler-Bonnet](https://github.com/ontologue) - tools for knowledge work, AI orchestration, semantic systems, and the craft of typesetting books.

---

## Projects

### 🔗 [mcp-neo4j](./mcp-neo4j/)

**Model Context Protocol server for Neo4j graph databases**

Query Neo4j directly from Claude Desktop (or any MCP client) via Cypher. Built because the official MCP Neo4j server didn't exist yet.

**Status:** ✅ Stable  
**Language:** Python  
**Stack:** MCP, Neo4j, asyncio

[→ Documentation](./mcp-neo4j/README.md)

---

### 📐 [designcraft](./designcraft/)

**Parent pages by paragraph style, and field notes from a 336-page book**

A Tk tool that applies parent pages according to the style at the top of each page, driven over DesignCraft's JSON control channel — plus the list of things that cost me days: 0-based page indices, commands to keep out of loops, the nested-style field that only appears once you guess where it is.

**Status:** 📝 Working tool, unmaintained notes — tested against DesignCraft 0.18.0 only  
**Language:** Python (Tk, no dependencies) + two batch files  
**Stack:** DesignCraft control channel, tkinter

[→ Documentation](./designcraft/README.md)

## Philosophy

**Tessellae** (Latin, plural of *tessella*) are the small pieces that form a mosaic. Each project here is a tessella - a focused, well-crafted tool that contributes to larger knowledge systems.

We build at our level of competence: humble tools that work, solve real problems, and respect the craft.
